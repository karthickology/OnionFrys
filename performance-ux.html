Performance Optimization

UX Metrics

A fast lab score doesn't guarantee a page feels fast to a real person — these metrics close that gap.

On this page

  1. Perceived performance vs. measured performance
  2. Time to Interactive and input responsiveness
  3. Mobile-specific UX considerations
  4. Tying UX metrics back to business outcomes

Perceived performance vs. measured performance

A page that renders a skeleton or placeholder immediately, then fills in content, often feels faster than one that shows nothing until everything is ready — even when the second one technically finishes loading sooner.

Time to Interactive and input responsiveness

A page can look fully loaded and still be unresponsive if the main thread is busy executing JavaScript. This is the gap between a page looking done and a page actually being usable, and it's a common source of frustrated clicks that seem to do nothing.

Mobile-specific UX considerations

Touch targets need real room (44x44px is the common minimum), thumb reach limits where primary actions should sit on a phone screen, and mobile networks vary far more than desktop connections — designing for the median case, not the best case, matters here.

Tying UX metrics back to business outcomes

Bounce rate and conversion rate both correlate with perceived speed closely enough that performance work is rarely just a technical concern — it shows up in the same reports marketing and product teams already care about.

Feels fast beats measures fast

If a choice has to be made between a slightly better lab score and a page that visibly responds to the user sooner, the second one usually wins in practice.

Action checklist

  • ✓Show a skeleton or placeholder instead of a blank screen while loading
  • ✓Test whether a page responds to input immediately, not just whether it looks loaded
  • ✓Confirm touch targets meet a 44x44px minimum on mobile
  • ✓Test on a throttled, median mobile connection, not just fast wifi
  • ✓Track bounce and conversion rate alongside any Core Web Vitals change
