Technical SEO

The invisible work that decides whether your content gets evaluated at all.

On this page

Crawlability and indexation

A robots.txt file and an accurate sitemap.xml tell search engines where they're allowed to go and what exists to find. Misconfigured noindex tags, accidental robots.txt blocks, and orphaned pages (no internal links pointing to them) are some of the most common — and most invisible — reasons a page never ranks.

Site architecture

A flat, logical structure keeps every page within a few clicks of the homepage and makes canonical tags easier to reason about. Canonical tags matter most when the same content is reachable through more than one URL — without one, search engines have to guess which version to trust.

Structured data

Schema markup (usually JSON-LD) doesn't change rankings directly, but it makes your content eligible for rich results — star ratings, FAQ dropdowns, breadcrumb trails in search. Article, FAQ, Breadcrumb, and Product schema cover most sites' needs.

Core Web Vitals as a ranking input

Page experience, measured largely through Core Web Vitals, is one of the few technical ranking factors Google has confirmed directly. It's covered in full in the Performance section, but it belongs on any technical SEO checklist.

Fix the foundation first

No amount of content or link building overcomes a page a crawler can't reach or won't index. When rankings stall unexpectedly, check the technical basics before anything else.

Action checklist

  • ✓Confirm robots.txt isn't blocking pages that should be indexed
  • ✓Submit an accurate, up-to-date sitemap.xml
  • ✓Check for orphaned pages with no internal links pointing to them
  • ✓Add canonical tags anywhere the same content is reachable via multiple URLs
  • ✓Validate structured data with a schema testing tool before publishing
