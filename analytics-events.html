Analytics & GA4

Event Tracking

GA4 tracks everything as an event — the skill is deciding which ones are worth naming.

On this page

  1. Automatically vs. manually collected events
  2. Naming events consistently
  3. Parameters that make events useful
  4. Testing before you trust the data

Automatically vs. manually collected events

GA4 collects a useful baseline automatically — page views, scrolls, outbound clicks, video engagement — with no setup required. Anything specific to your site's actual goals (a form submission, a product configurator step, a pricing toggle) needs to be instrumented manually.

Naming events consistently

Agreeing on a naming convention before implementation starts — verb_noun, like generate_lead or start_trial — prevents the common failure mode of ending up with three slightly different event names all tracking the same action.

Parameters that make events useful

A single generic "click" event tells you little. The same event with parameters attached (button_location, form_name, item_category) turns one event into something that can be filtered and compared, without creating a new event for every variant.

Testing before you trust the data

DebugView and the real-time report let you fire an event and confirm it arrived with the right parameters before it's live in production. A quick QA pass here catches most naming and parameter mistakes before they pollute weeks of data.

Fewer events, better parameters

Most sites overcorrect toward tracking too many narrowly-named events instead of fewer events with rich parameters. The second approach is almost always easier to analyze later.

Action checklist

  • ✓Document a naming convention before instrumenting any custom event
  • ✓Attach parameters instead of creating a new event per variant
  • ✓Verify every custom event in DebugView before shipping
  • ✓Avoid duplicating an event GA4 already collects automatically
  • ✓Review event names quarterly for accidental duplicates

These checklists are meant to be used, not just read. Reach out if you want a second pair of eyes on your setup.
